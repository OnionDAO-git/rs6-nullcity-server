# S-AP-CYCLE-1 - Ordinary No-Floor AP/GP Self-Funding Cadence

Date: 2026-05-31

## TL;DR

S-AP-CYCLE-1 implements the low-risk Option A from `docs/superpowers/specs/2026-05-31-ap-decay-cycle-design.md`: no-floor residents with real RuneScape GP now consider AP self-funding below `3000 AP` instead of waiting until `300 AP`, and the target runway is `3500 AP` instead of `500 AP`.

This does not change hero/floor resident behavior. Heroes still need a separate surplus-GP top-up packet because their AP floors intentionally clamp them above ordinary no-floor trigger logic.

## Why

The fresh 60m normal-life audit showed GP-holding residents above the old `300 AP` trigger, so organic exchange would require roughly 3.7 hours from a default 5000 AP start. That cadence is too slow for the CIC/Chicago loop where humans should see residents spend AP, earn real GP item `995`, and buy themselves more Attention.

## Change

Files:

- `src/controller/spark/self-initiated-ap-gp-exchange.ts`
- `src/controller/admin/normal-life-audit.ts`

Behavior:

- `SELF_INITIATED_EXCHANGE_NO_FLOOR_AP_THRESHOLD`: `300 -> 3000`.
- `SELF_INITIATED_EXCHANGE_TARGET_RUNWAY_AP`: `500 -> 3500`.
- Existing safeguards stay intact: minimum `10 GP`, maximum `250 GP` burned per exchange, `2 AP / GP`, and floor-protected residents still use `attentionFloor + 20`.
- `normal-life-audit` now reports `exchangeThresholdAp` and `apUntilExchangeThreshold` for GP-holding residents, plus `residentsApproachingExchangeThreshold`.

## Risk Notes

- Raising target runway to `3500` does not burn unlimited GP: `SELF_INITIATED_EXCHANGE_MAX_GP=250` still caps each self-funding action at `500 AP`.
- First exchange cadence from a default `5000 AP` start is now roughly 90-100 minutes instead of 3.7 hours at the observed AP drain rate. Recurrence after an exchange is expected roughly every 20-25 minutes if GP remains.
- Hero/floor resident participation is deliberately out of scope. The next packet should implement a separate hero surplus-GP top-up rule if heroes must visibly spend GP for AP.
