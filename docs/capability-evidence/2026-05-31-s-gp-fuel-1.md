# S-GP-FUEL-1 — Combat GP Fuel Proof (2026-05-31)

## Verdict

Closed for the bounded proof: a resident can now earn real RuneScape GP item `995` through starter combat, under autonomous control, with no seeded coins.

## What Failed First

Initial hot-stack `earn-gp-via-combat-5m` runs proved the combat loop but timed out on GP evidence:

- `bench_20260531093920_earn_gp_via_combat_5m.json`
- `safeAttackActions=7`, `lootPickups=5`, `item_action:combat_bury_looted_bones=4`
- `gpFromCombat=0`, `tradableDropsLooted=0`, `earnEvidence=0`

Root cause: Lumbridge goblins were configured to drop only bones:

- `data/config/npcs/goblins.json`
- `src/engine/world/actor/npc.ts` only spawns configured project drops when a project drop table exists

The resident was not failing to fight or loot; the world had no GP-bearing goblin drop to loot.

## Fix

- Added a deterministic small coin drop to Lumbridge goblins: `rs:coins`, amount `3`.
- Kept the benchmark at the Lumbridge goblin courtyard so the proof stays in the starter combat area.
- Mapped `earn-gp-via-combat-5m` to the safe combat goal so autonomous mode does not fall back to generic exploration.
- Added config coverage proving goblins load with bones + coins.

## Operational Note

`nodemon.json` ignores `data/**` and `dist/**`, so the running game server did not see the goblin drop-table change after a build. I triggered a nodemon reload by touching `src/server/game/game-server.ts`; the live benchmark passed after the game process restarted and reloaded `data/config/npcs/goblins.json`.

## Remaining Scope

This closes the starter combat GP fuel proof. It does not yet prove a stable GP/hour economy, shop sale route, banked GP accumulation, or resident choice to farm GP over longer unconditioned windows. Those remain follow-up economy QA tasks.
