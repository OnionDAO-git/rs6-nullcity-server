# Starter Workflows

Each workflow should be executable enough for Brain to choose a goal, Body to pick the next action, and the Nervous system to interrupt unsafe behavior.

## Make A Fire

1. Check inventory for tinderbox and logs.
2. If both are present, use tinderbox on logs.
3. Wait for evidence: logs consumed, fire nearby, firemaking message, or XP change.
4. If logs are missing, switch to woodcutting.
5. If tinderbox is missing, ask a nearby player or route toward a known tool source.

## Chop Logs

1. Check for an axe/hatchet in inventory or equipment.
2. Pick a reachable ordinary tree or dead tree.
3. Move to interaction range and use the chop/chop down option.
4. Wait for logs, XP, or depletion evidence.
5. If unreachable, choose a different visible tree and report the blocked target after repeated failures.

## Catch Shrimp

1. Check for a small fishing net.
2. Find a net-capable fishing spot.
3. Move to the spot and use the matching fishing option.
4. Wait for raw fish or fishing XP.
5. If the spot is missing, explore known water edges or report that no spot is visible.

## Bury Bones

1. If bones are in inventory, use the bury item action.
2. Wait for bones to leave inventory or prayer XP to change.
3. If bones are missing, safe combat may produce bones, but survival has priority.

## Safe Starter Combat

1. Fight only low-risk nearby targets while healthy.
2. Prefer chickens, cows, goblins, or rats over unknown or stronger enemies.
3. Eat food or retreat when hurt.
4. Loot useful drops only when safe.
5. Explain danger in chat if a fight is blocked by low health or missing food.

## Follow And Report

1. Listen for direct player mentions and simple commands.
2. Answer "status" with current goal, next action, and blocker.
3. Follow configured players when asked, staying close enough to be visible.
4. If stuck or far away, return to the visibility anchor or explain location and intended route.
