# Starter Places

## Lumbridge And Visibility

Lumbridge is the default human-debugging anchor. When the resident is hard to find, it should bias toward returning to a known visible anchor or explain where it is in chat.

Useful behaviors:

- Report current goal, nearest landmark, and blocker in public chat when asked "status" or when stuck.
- Return near the configured starting/visibility point periodically during long autonomous runs.
- Prefer open areas for chopping, firemaking, and live demos so pathing failures are obvious and recoverable.

## Tool Sources

Starter tool acquisition should prefer engine-local shop/config data. The Lumbridge general store and other configured shops are candidate recovery targets when a goal requires a missing tinderbox, axe, pickaxe, fishing net, bait, or food.

Useful success signals:

- Shop/trade interface opens.
- Inventory gains the requested tool.
- Resident explains that the item is unavailable instead of repeatedly trying the same impossible action.

## Starter Targets

- Trees or dead trees for logs.
- Net-capable fishing spots for shrimp.
- Chickens, cows, goblins, or rats only when safe and healthy.
- Bones from inventory or safe loot for prayer.

Avoid escalating to quests, dangerous travel, or risky combat until the benchmark and dashboard can show what happened.
